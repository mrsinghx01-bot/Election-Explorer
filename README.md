# ⚡ Election Explorer — Interactive Democracy

An interactive, premium web application to learn about the democratic election process through guided stages, quizzes, scenario simulations, and an AI chatbot assistant.

🌐 **Live Demo:** [election-explorer-166227200902.us-central1.run.app](https://election-explorer-166227200902.us-central1.run.app/)

## ✨ Features

- **6 Election Stages** — From announcement to government formation, each stage is explained in simple, beginner-friendly language with illustrations.
- **Democracy Quiz** — 15 interactive questions to test your knowledge of the election process with instant feedback.
- **Scenario Simulator** — Explore hypothetical scenarios like Hung Parliament, Recount, Coalition Formation, and Election Disruption.
- **DemoBot Chatbot** — An AI-powered assistant to answer your questions about elections, voting, and EVMs.
- **Dark/Light Theme** — Toggle between themes with persistent preference.
- **Aurora Background & Particle Effects** — Premium animated background with election-themed floating emojis.
- **Fully Responsive** — Works seamlessly on desktop, tablet, and mobile.

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, animations, glassmorphism effects
- **Vanilla JavaScript** — No frameworks, pure JS
- **Express.js** — Lightweight server for deployment
- **Google Cloud Run** — Production deployment

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start the server
npm start
```

Then open [http://localhost:8080](http://localhost:8080) in your browser.
